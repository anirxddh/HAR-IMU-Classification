# HAR Outputs

## Purpose

This directory contains artifacts generated by the Human Activity Recognition workflow. It separates visualizations, serialized models, and machine-readable result tables so that outputs can be inspected, reproduced, or reused independently of the source notebooks.

## Directory Structure

| Location | Purpose |
|---|---|
| [`figures/`](./figures/) | Generated plots and report-quality visualizations |
| [`models/`](./models/) | Trained classical models and CNN/TensorFlow Lite artifacts |
| [`results/`](./results/) | CSV tables for tuning, cross-validation, metrics, deployment, and testing |

## Use Case

Use this directory as the evidence package for:

- Reporting preprocessing and class balance.
- Comparing model accuracy and stability.
- Inspecting misclassification patterns.
- Estimating deployment size and runtime cost.
- Loading a trained model for inference.

Generated artifacts should be reproduced using the pipeline rather than edited manually.
