# Generated Figures

## Purpose

This directory contains PNG plots produced by [`har_ai_ml.py`](../../har_ai_ml.py) and the corresponding notebook. The figures document preprocessing decisions, model comparison, cross-validation stability, and deployment trade-offs.

## Figure Groups

| Prefix | Purpose |
|---|---|
| `2_` | Data preprocessing, class balance, PCA, and LDA |
| `5_` | Cross-validation stability |
| `cnn_` | CNN training and validation curves |
| `8_` | Model comparison, confusion matrices, ROC curves, and size trade-off |
| `9_` | Final test-set confusion matrix |

## Use Case

Use these files in reports, presentations, or model-review discussions. Figures are saved at 150 DPI with tight layout margins unless the source plotting code specifies otherwise.
