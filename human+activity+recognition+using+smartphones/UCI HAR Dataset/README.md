# UCI HAR Dataset Archive Wrapper

## Purpose

This directory forms part of the local extraction layout for the UCI HAR dataset. It contains the nested dataset directory used by the implementation.

## Use Case

The workflow should resolve the actual dataset at:

`UCI HAR Dataset/UCI HAR Dataset/`

Do not move or rename the nested directory unless the corresponding data paths in [`har_ai_ml.py`](../../har_ai_ml.py) are updated.
